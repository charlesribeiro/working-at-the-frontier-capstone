# Working at the Frontier — Module 8 Capstone

This repository contains a completed engagement simulation from the Taller Technologies Frontier Engineer onboarding course.

The scenario concerns Meridian Health Services, a fictional/hypothetical organization, and its provider-credentialing workflow. It does not represent the operations of CVS Health or any other real organization.

The capstone demonstrates:

- end-to-end flow analysis, bottleneck diagnosis, and flow-efficiency calculation;
- outcome definition, quality guardrails, and falsification conditions;
- workflow redesign and the distinction between deterministic automation and AI/agent judgment;
- shared context, identity, accountability, and least-privilege agent design;
- security, data-residency, and human/agent workflow considerations;
- executive and client communication under stakeholder pushback; and
- self-assessment and retrospective critique.

This is an educational simulation. The repository contains no production client data.
